What was checked

  • the SHA-256 digest recomputed from the certificate body
  • for each link of an ECPP chain: the point lies on the curve, the claimed order satisfies the Hasse bound, q divides m, q > (N1/4+1)², m·P = O and (m/q)·P ≠ O
  • that the chain decreases and each link's q is the next link's N
  • that the chain is closed — the final q is below 264, where Miller-Rabin is deterministic, or carries a Pocklington proof
  • for a recovered RSA factor: that it really divides the modulus

An unknown format, an unknown claim, an unknown proof method or a missing proof are all reported as invalid. Nothing is assumed.

Nothing leaves this tab

This page makes no network requests while verifying. Disconnect and it still works; open the network tab and watch. The arithmetic is plain BigInt in kp-verify.js — about six hundred lines you can read in an afternoon, with no dependencies.

This is a second, independent implementation. The Python verifier in the same repository and this one were written from the specification, not from each other, and are tested to agree on every certificate here — including byte-identical digests.
